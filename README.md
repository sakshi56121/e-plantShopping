# e-plantShopping - Paradise Nursery

## Project Description

Paradise Nursery is a React-based online plant shopping application.

It allows users to browse different categories of plants, add plants to a shopping cart, manage quantities, remove items, and view the total cart amount.

## Features

- Paradise Nursery landing page
- About Us section
- Plant categories
- Plant product cards
- Add to Cart functionality
- Redux state management
- Shopping cart
- Increase and decrease quantity
- Remove items from cart
- Total price calculation
- Checkout button

## Technologies Used

- React.js
- Vite
- Redux Toolkit
- React Redux
- JavaScript
- CSS
